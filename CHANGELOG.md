# Changelog

All notable changes to this project are documented here. The format follows

## [0.1.0] - 2026-07-25

### Added

- Client-side `api_signal` parsing, raw-data inspection, latency statistics,
  timeline, and histogram.
- Three versioned sample logs with documented provenance.
- Size-limited local uploads and privacy-preserving custom URL loading.
- Native Codex and Claude five-stage development pipelines.
- Automated quality, security, dependency, and GitHub Pages workflows.
